# Agulha_douro_site_vitrine

A corporate website developed for **Atelier Agulha D'Ouro**, a fashion atelier specializing in haute couture, bridal gowns, and custom-made garments. This project was created with the intention of building an online presence for my grandparents' business, helping them showcase their work and reach a wider audience. The website presents the brand's services, collections, and company information through a modern, responsive, and SEO-friendly interface, providing an elegant and intuitive user experience across all devices.

## Technologies

* Next.js
* React
* Tailwind CSS
* JavaScript

## Features

* Modern landing page with a hero section
* Company presentation
* Collections showcase
* Contact page
* Customer complaints form
* Responsive design for desktop, tablet, and mobile
* SEO optimization
* Clean and maintainable codebase
